# Aoede for Android

Connect to your Aoede server, listen online or offline, and control playback through the app, notification, home-screen widget or optional Dynamic Island. Classic, Glass and Vitrine are available in Appearance & settings.

- [Installation, updates and device options](../docs/ANDROID.md)
- [Appearance themes](../docs/THEMES.md)
- [Security guidance](../docs/SECURITY.md)

In the main repository these guides are in the parent `docs/` directory. In the Android source download they are included in this directory.
